# Remote debug protocol fixtures

Binary test vectors for `DEBUG_PROTOCOL.md`. Every file is one complete protocol message (or, for
`value_*.bin`, one bare value). An implementation should decode each file and assert the values below,
and encode the same values and compare the bytes.

This file is generated by `FlixelDebugProtocolTest` (run the tests with `FLIXEL_REGEN_FIXTURES=1`).
Do not edit it by hand. Notation: `type:value` fields appear in wire order; `array[ ... ](count N)`
is a `u16` count followed by the elements; `value:KIND:x` is a value (kind byte then data);
`value:LIST[ ... ](count N)` is a list value (kind byte, `u16` count, then the items);
`\u{XXXX}` is a Unicode code point written as UTF-8. Feed indices used: stats 0, logs 1, watches 2,
trackers 3, textures 4, controls 5, console 6, scene 7, inspector 8, save 9, viewport 10,
capture 11, input 12. Panel messages use panel index 3.
